## 中文介绍

> AI 内容创作与多平台发布桌面工具
>
> 选题素材 → AI 写作 → 模板排版 → 多平台发布，一条流水线完成。

这是一款多平台内容生产桌面工具，覆盖公众号、头条号、百家号和小红书（贴图）等内容场景，帮助个人博主、代运营团队和内容创作者完成从选题到发布的全流程。生成的文章自然、无 AI 痕迹，**内容 100% 过 AI 检测**。

主要能力包括：

- 从热点/爆文中快速选题
- AI 生成文章大纲、正文、排版
- 一键制作公众号贴图（首图 + 内容卡）
- 自动/手动配图
- 多平台账号管理和内容发布（公众号、头条号、百家号、小红书贴图）
- 定时自动托管生成并发布内容

账号凭据和创作数据保存在本机，不经过第三方。

## 中文核心能力

### 1. 资源管理

- **今日热点**：实时更新的热点文章，可用于选题和二次创作
- **微信爆文**：微信生态爆文聚合，支持一键带入创作工坊
- **图片素材**：平台自动收集图片素材并进行 AI 打标，支持按标签筛选、搜索；已打标图片可作为文章配图
- **我的图片**：个人图库，支持上传图片并自定义标签
- **我的素材**：支持导入 TXT 素材，也支持 AI 按账号定位批量生成内容大纲；素材可编辑，供自动托管使用
- 素材完全自定义：用户自建素材组、批量导入、AI 生成、逐条编辑修改，素材不限于文本，可配合指定排版模板/首图模板使用，托管任务可直接绑定

### 2. 创作工坊

**文章模式**

- 输入主题/素材，AI 自动生成：爆款标题 → 文章大纲 → 完整正文 → 排版
- 成品自然真人风格，无 AI 痕迹，100% 过 AI 检测
- 内置多套公众号排版模板，支持主题生成器、自定义模板（另存为我的模板）
- 排版完全自定义：基于任意内置模板修改配色、字体、字号、样式参数，或直接写自定义 CSS 微调，另存为「我的模板」后与内置模板同等使用
- 自动配图：从图片素材库按文章内容匹配，或从个人图库选择
- 字数可选 800 / 1200 / 1500 或自定义
- 富文本编辑：标题、引用、卡片、列表、分割线、CTA 等组件
- 手机效果预览，支持复制 HTML 到公众号后台

**贴图模式**

- AI 根据主题生成：贴图标题 + 分段正文 + 话题
- 首图模板 + 内容卡模板，标题渲染到首图、正文逐段渲染成卡片
- 内置 50+ 首图模板，按风格分类
- **自定义模板（高级版）**：可上传背景图、配置文字区域（位置/字号/颜色/对齐/行数）、自定义 CSS，另存为我的模板后全端通用
- 贴图素材自定义：除了内置模板，用户可上传自己的首图/内容卡背景图，自由划定标题和正文的文字区域，保存成个人模板库
- 贴图发布到公众号，正文自动带话题

### 3. 账号中心

- 支持公众号、头条号、百家号扫码/网页登录（小红书支持贴图发布），Cookie 自动保存
- 公众号支持同步名下多个公众号，标记当前生效账号
- 账号开关、原创/首发/AI 声明等配置持久化保存
- 一键前往平台后台

### 4. 内容发布

- 文章/贴图统一发布：先选平台 → 再选账号（联动），支持公众号、头条号、百家号发布，公众号支持保存草稿箱，贴图支持发布到小红书
- 发布历史分页，可按平台/账号筛选
- 生成记录与发布状态联动，避免重复发布

### 5. 自动托管

- 创建定时任务：每天/一次、每次成功篇数、开始时间 + 间隔
- 内容来源：我的素材 / 今日热点 / 微信爆文
- 支持文章和贴图（贴图可发布到公众号/小红书），公众号需选择具体账号
- 素材已使用自动标记，不重复消耗
- 任务执行日志实时查看，失败自动重试

### 6. 个人中心

- 授权状态、套餐、到期时间、积分余额一目了然
- 套餐购买 / 续费：微信扫码支付，支付后自动生效（同一授权）
- 积分记录：AI 使用扣费流水
- 订单记录：购买/续费订单及支付状态
- 软件更新：自动检测新版本，后台下载、自动安装
- 客服微信 / 二维码

### 安全与隐私

- 账号 Cookie/登录态仅保存在本机
- AI 网关调用只传递生成内容，不采集个人数据
- 安装包不内置任何 API 密钥

4. **排版费时间、发布繁琐**
   - 内置多套排版模板 + 自定义模板，一键套用
   - 账号中心统一管理多平台登录态，内容发布先选平台再选账号

5. **内容一眼 AI 味**

## 中文使用方式

1. 下载并安装桌面客户端。
2. 在「账号中心」扫码或网页登录公众号、头条号、百家号、小红书。

## English Overview

This is a desktop tool for AI content creation and multi-platform publishing.

It covers content scenarios such as WeChat Official Accounts, Toutiao, Baijiahao, and Xiaohongshu (image posts), helping individual bloggers, agency teams, and content creators complete the full workflow from topic selection to publishing.

Generated articles read naturally with no AI traces; **content passes AI detection 100%**.

The pipeline covers: topic selection from trending / viral articles → AI writing → templated layout → multi-platform publishing.

Account credentials and creation data are stored locally and are not sent to third parties.

Core capabilities:

- Quickly select topics from trending / viral articles
- AI generates article outlines, body text, and layout
- One-click creation of WeChat Official Account image posts (cover image + content cards)
- Automatic / manual image matching
- Multi-platform account management and content publishing (WeChat Official Account, Toutiao, Baijiahao, Xiaohongshu image posts)
- Scheduled automated hosting for content generation and publishing

## English Features

### 1. Resource Management

- **Today's Hot Topics**: Real-time hot articles that can be used for topic selection and re-creation
- **WeChat Viral Articles**: Aggregated viral articles from the WeChat ecosystem, can be brought into the Workshop with one click
- **Image Library**: Platform automatically collects image assets and performs AI tagging; tag-based filtering and search are supported; tagged images can be used as article illustrations
- **My Images**: Personal image library, upload images and customize tags
- **My Materials**: Import TXT materials, or use AI to batch-generate content outlines per account positioning; materials are editable for use in automated hosting
- Materials are fully customizable: users build their own material groups, batch-import, AI-generate, and edit each item; materials are not limited to text and can be paired with specified layout / cover image templates; hosting tasks can be directly bound to materials

### 2. Workshop

**Article Mode**

- Enter a topic / material, and AI automatically generates: viral title → article outline → full body → layout
- Output reads naturally in a real-person style with no AI traces, passing AI detection 100%
- Built-in WeChat Official Account layout templates, with a theme generator and custom templates (save as "My Templates")
- Fully customizable layout: modify colors, fonts, font sizes, and style parameters on any built-in template, or write custom CSS to fine-tune, then save as "My Templates" for the same usage as built-in templates
- Automatic image matching: match from the Image Library by article content, or pick from the personal image library
- Word count options: 800 / 1200 / 1500, or custom
- Rich-text editing: titles, quotes, cards, lists, dividers, CTA components, etc.
- Mobile preview, supports copying HTML to the WeChat Official Account backend

**Image Post Mode**

- AI generates from the topic: image post title + segmented body + hashtags
- Cover image template + content card template; the title is rendered onto the cover image, and the body is rendered into cards segment by segment
- 50+ built-in cover image templates, categorized by style
- **Custom Templates (Advanced)**: upload background image, configure text regions (position / font size / color / alignment / number of lines), custom CSS, save as "My Templates" for use across all endpoints
- Image-post material customization: beyond built-in templates, users can upload their own cover image / content card background images, freely define text regions for title and body, and save into a personal template library
- Publish image posts to WeChat Official Account; the body automatically carries hashtags

### 3. Account Center

- QR-code / web login supported for WeChat Official Account, Toutiao, and Baijiahao (Xiaohongshu supports image-post publishing); cookies are saved automatically
- WeChat Official Account supports syncing multiple accounts under the same name, with a currently active account marker
- Account toggles, original / first-published / AI disclosure configurations are persisted
- One-click access to platform backends

### 4. Content Publishing

- Unified publishing for articles / image posts: pick platform first → then pick account (linked). Supports publishing to WeChat Official Account, Toutiao, and Baijiahao; WeChat Official Account supports saving to drafts; image posts can be published to Xiaohongshu
- Publishing history with pagination, filterable by platform / account
- Generation records are linked with publishing status to avoid duplicate publishing

### 5. Automated Hosting

- Create scheduled tasks: daily / one-time, number of articles per successful run, start time + interval
- Content sources: My Materials / Today's Hot Topics / WeChat Viral Articles
- Supports articles and image posts (image posts can be published to WeChat Official Account / Xiaohongshu); a specific account must be selected for WeChat Official Account
- Used materials are automatically marked to avoid repeat consumption
- Real-time task execution logs, automatic retry on failure

### 6. Personal Center

- Authorization status, plan, expiration date, and credit balance at a glance
- Plan purchase / renewal: WeChat QR-code payment, takes effect automatically after payment (same authorization)
- Credit records: AI usage deduction history
- Order records: purchase / renewal orders and payment status
- Software updates: automatic detection of new versions, background download and auto-install
- Customer service WeChat / QR code

### Security and Privacy

- Account cookies / login states are stored only on the local machine
- AI gateway calls only transfer generation content and do not collect personal data
- The installer does not embed any API keys
