## 中文介绍

万稿汇是一款多平台内容生产桌面工具，覆盖公众号、头条号、百家号和小红书（贴图）等内容场景，帮助个人博主、代运营团队和内容创作者在一套流水线内完成从选题、写作、排版到多平台发布的全部环节。

工具强调生成内容的自然度：成品文章自然、口语化、无 AI 痕迹，**内容 100% 过 AI 检测**。账号凭据（Cookie / 登录态）与创作数据均保存在本机，不经过第三方；AI 网关调用仅传递生成内容，不采集个人数据；安装包不内置任何 API 密钥。

## 中文核心能力

### 资源管理

- **今日热点**：实时更新的热点文章，可用于选题和二次创作
- **微信爆文**：微信生态爆文聚合，支持一键带入创作工坊
- **图片素材**：平台自动收集图片素材并进行 AI 打标，支持按标签筛选、搜索；已打标图片可作为文章配图
- **我的图片**：个人图库，支持上传图片并自定义标签
- **我的素材**：支持导入 TXT 素材，也支持 AI 按账号定位批量生成内容大纲；素材可编辑，供自动托管使用
- 素材完全自定义：用户自建素材组、批量导入、AI 生成、逐条编辑修改；素材不限于文本，可配合指定排版模板 / 首图模板使用，托管任务可直接绑定

### 创作工坊

**文章模式**

- 输入主题 / 素材，AI 自动生成：爆款标题 → 文章大纲 → 完整正文 → 排版
- 成品自然真人风格，无 AI 痕迹，100% 过 AI 检测
- 内置多套公众号排版模板，支持主题生成器、自定义模板（另存为我的模板）
- 排版完全自定义：基于任意内置模板修改配色、字体、字号、样式参数，或直接写自定义 CSS 微调，另存为「我的模板」后与内置模板同等使用
- 自动配图：从图片素材库按文章内容匹配，或从个人图库选择
- 字数可选 800 / 1200 / 1500 或自定义
- 富文本编辑：标题、引用、卡片、列表、分割线、CTA 等组件
- 手机效果预览，支持复制 HTML 到公众号后台

**贴图模式**

- AI 根据主题生成：贴图标题 + 分段正文 + 话题
- 首图模板 + 内容卡模板，标题渲染到首图、正文逐段渲染成卡片
- 内置 50+ 首图模板，按风格分类
- **自定义模板（高级版）**：可上传背景图、配置文字区域（位置 / 字号 / 颜色 / 对齐 / 行数）、自定义 CSS，另存为我的模板后全端通用
- 贴图素材自定义：除了内置模板，用户可上传自己的首图 / 内容卡背景图，自由划定标题和正文的文字区域，保存成个人模板库
- 贴图发布到公众号，正文自动带话题

### 账号中心

- 支持公众号、头条号、百家号扫码 / 网页登录（小红书支持贴图发布），Cookie 自动保存
- 公众号支持同步名下多个公众号，标记当前生效账号
- 账号开关、原创 / 首发 / AI 声明等配置持久化保存
- 一键前往平台后台

### 内容发布

- 文章 / 贴图统一发布：先选平台 → 再选账号（联动），支持公众号、头条号、百家号发布，公众号支持保存草稿箱，贴图支持发布到小红书
- 发布历史分页，可按平台 / 账号筛选
- 生成记录与发布状态联动，避免重复发布

### 自动托管

- 创建定时任务：每天 / 一次、每次成功篇数、开始时间 + 间隔
- 内容来源：我的素材 / 今日热点 / 微信爆文

- 任务执行日志实时查看，失败自动重试

## 中文使用场景

- **没有灵感、不知道写什么**：今日热点、微信爆文实时聚合，选题库现成可用；我的素材支持导入和 AI 生成，按账号定位批量产出选题大纲；一条主题 / 素材，AI 直接生成标题、大纲、正文。
- **不会打造账号人设**：在 AI 生成素材时输入「账号定位 / 主题」，大模型按人设产出内容；同一素材组的历史大纲会回传给大模型，保持人设连续、避免重复；素材可编辑、可沉淀，形成账号自己的选题库和内容资产。
- **配图没有准确标签**：图片素材由平台 AI 自动打标，不需要手工分类；自动配图按文章内容和标签匹配；个人图库支持上传图片并自定义标签，标签即筛选用。
- **排版费时间、发布繁琐**：内置多套排版模板 + 自定义模板，一键套用；账号中心统一管理多平台登录态，内容发布先选平台再选账号；自动托管按计划批量生成并发布，素材用完自动标记不重复。
- **内容一眼 AI 味**：成品文章自然、口语化，符合真人创作习惯，100% 过 AI 检测。

## 中文使用方式

1. 在「账号中心」扫码 / 网页登录公众号、头条号、百家号（小红书支持贴图发布），Cookie 自动保存在本机。
2. 通过「今日热点」「微信爆文」「我的素材」完成选题与素材准备，可直接导入 TXT，也可让 AI 按账号定位批量生成内容大纲。
3. 在「创作工坊」中输入主题或素材，进入文章模式或贴图模式：AI 自动生成爆款标题、大纲与正文，并套用内置排版模板或自定义模板，可一键自动配图，也可从个人图库手动选图。
4. 在「内容发布」中先选平台、再选账号（联动）发布；公众号可选择保存草稿箱；贴图可发布到小红书。
5. 在「自动托管」中创建定时任务（每天 / 一次、每次成功篇数、开始时间 + 间隔），内容来源可选我的素材 / 今日热点 / 微信爆文；素材已使用自动标记，不会重复消耗。
6. 在「个人中心」查看授权状态、套餐到期时间、积分余额与积分扣费流水，完成套餐购买 / 续费，并查看软件更新。
